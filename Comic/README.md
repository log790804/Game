# Comic

Windows 原生單機漫畫管理器與離線閱讀器，使用 .NET 10 與 WPF。

## 目前 MVP 目標

1. 輸入 HappyMH 漫畫網址並載入漫畫與章節資訊。
2. 勾選章節後，依章節及頁碼順序下載。
3. 支援暫停、繼續、失敗重試與中斷後續跑。
4. 從本機漫畫庫進行離線閱讀並保存閱讀進度。

## 真人驗證流程

當一般載入收到 HTTP 403 或網站顯示真人驗證時：

1. 在漫畫網址右側選擇「手動驗證…」。
2. 在內嵌的 Microsoft Edge WebView2 視窗中親自完成驗證。
3. 確認已回到漫畫詳情頁，等待章節清單出現。
4. 選擇「驗證完成並載入」。程式會讀取目前頁面的章節資料，並將該 HappyMH 工作階段安全地提供給下載器。

WebView2 的瀏覽器工作階段保存在 `%LocalAppData%\Comic\WebView2Profile`。Cookie 不會寫入應用程式設定或日誌。

## 離線書庫與閱讀紀錄

下載內容使用固定結構：

```text
漫畫庫根目錄/（預設 `D:\Game\Game\Comic\Library`）
└─ 漫畫 ID/
   ├─ comic-info.json
   └─ 第N回/
      ├─ 0001.jpg
      ├─ 0002.jpg
      └─ ...
```

- 正常編號章節使用 `第1回`、`第2回`、…、`第10回`，掃描時依數字自然排序。
- 公告或無法辨識回數的內容使用 `其他_章節ID`，避免與正常章節互相覆蓋。
- `comic-info.json` 保存漫畫 ID 與網站漫畫名稱的關聯；離線閱讀下拉選單優先顯示漫畫名稱，缺少或損壞時才退回資料夾 ID。
- 新下載會自動建立或更新關聯檔；既有漫畫則會從下載歷史自動補建，不需要重新下載圖片。
- 離線閱讀頁會將整回圖片垂直排列，可用滑鼠滾輪或捲軸連續閱讀。
- 長條漫畫預設以 760px 最大寬度顯示；可在閱讀頁用滑桿或 −／+ 調整為 480–1200px，重設不會修改原始圖片。
- 捲動時會依畫面中主要顯示的圖片更新頁碼與閱讀進度。
- 每回底部可直接接續下一回，上方按鈕與左右方向鍵也能切換回數。
- 每本漫畫會記錄最後閱讀的章節和圖片；重新啟動後會自動恢復最近閱讀位置。
- 閱讀紀錄保存在 `%LocalAppData%\Comic\reading-history.json`，不包含網站 Cookie。

## 下載歷史與續傳

- 每個完整下載的章節都會寫入下載歷史；既有的完整本機章節也會在載入漫畫時補入紀錄。
- 已完成且本機圖片數量足夠的章節會從可下載清單排除，避免重複選取與重複下載。
- 若歷史紀錄存在但本機圖片遺失或數量不足，該章節會重新出現在可下載清單中。
- 每張圖片下載前都會檢查本機檔案；已存在的頁面直接跳過，因此中斷後可以安全續傳。
- 下載歷史保存在 `%LocalAppData%\Comic\download-history.json`，依漫畫庫位置、漫畫與章節區分。

## 安全與使用限制

- 只允許 HTTPS 與明確白名單網域。
- 不會自動解答或規避 CAPTCHA；真人驗證必須由使用者親自完成。
- 不繞過登入、付費牆或其他存取控制。
- 下載功能僅供保存使用者有權離線使用的內容。
- 漫畫與執行資料保存在 `Library/`，預設不提交 Git。

## 開發命令

```powershell
dotnet restore Comic.sln
dotnet test Comic.sln
dotnet build Comic.sln --configuration Release
dotnet run --project src/Comic.Desktop/Comic.Desktop.csproj
```
