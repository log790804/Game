# TD Game

本資料夾用來集中放置塔防遊戲的前期規劃內容。現階段只保存設計文件，不實作 Vue、Phaser 或遊戲程式碼。

## 專案定位

- 類型：2D 塔防網頁遊戲
- 建議技術：Vue 3 + Vite + TypeScript + Phaser
- 目標平台：桌機瀏覽器與行動裝置瀏覽器
- UI 分工：Vue 負責選單、HUD、成就、科技樹、設定；Phaser 負責遊戲地圖、塔、敵人、子彈、特效與戰鬥流程。

## 已納入規劃的功能

- 多關卡
- 技能系統
- 成就系統
- 本機存檔
- 塔科技樹
- 每日挑戰
- 音效與背景音樂
- 行動版觸控操作
- 難度選擇
- 塔稀有度與升級限制
- 塔攻擊範圍與特殊效果
- 組合塔、共鳴塔、合成塔
- 遊戲素材規劃
