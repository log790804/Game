# 塔系統規劃

## 塔的核心欄位

每座塔建議具備以下資料：

- towerId
- towerName
- rarity
- baseDamage
- attackSpeed
- attackRange
- attackType
- maxLevel
- upgradeCost
- effects
- techTreeTags
- buildLimit
- comboTags

## 稀有度與最高等級

| 稀有度 | 定位 | 最高等級 | 特點 |
|---|---|---:|---|
| 普通 | 前期基礎塔 | Lv.5 | 便宜、穩定、效果少 |
| 稀有 | 中期主力塔 | Lv.7 | 有明確特殊效果 |
| 史詩 | 後期核心塔 | Lv.9 | 可改變打法 |
| 傳說 | 關卡王牌塔 | Lv.10 | 高傷害或強控場 |
| 神話 | 特殊解鎖塔 | Lv.12 | 數量限制，終局目標 |

## 攻擊範圍

| 範圍類型 | 建議數值 | 適合塔 |
|---|---:|---|
| 短距離 | 90-120 | 火焰塔、毒塔、範圍塔 |
| 中距離 | 130-170 | 箭塔、砲塔、冰塔 |
| 長距離 | 180-230 | 狙擊塔、雷電塔、魔法塔 |
| 超遠距離 | 250+ | 傳說塔、Boss 專用塔 |

不建議大量使用全圖攻擊。全圖效果應保留給技能、每日挑戰特殊規則或神話塔終極效果。

## 組合塔系統

組合塔讓塔的位置與搭配變成策略重點。

### 組合類型

| 類型 | 說明 |
|---|---|
| 鄰近組合 | 指定塔放在 1-2 格範圍內觸發 |
| 數量組合 | 場上有指定數量塔時觸發 |
| 屬性組合 | 同屬性或互補屬性塔互相強化 |
| 稀有度組合 | 高稀有塔強化低稀有塔 |
| 合成組合 | 多座高等塔消耗後合成新塔 |
| 陣型組合 | 塔依照十字、三角、核心陣排列 |
| 科技樹組合 | 需要先解鎖科技才能觸發 |

### 組合範例

| 組合名稱 | 需求 | 效果 |
|---|---|---|
| 冰雷共鳴 | 冰塔 + 雷塔相鄰 | 雷塔攻擊緩速敵人時傷害 +30% |
| 燃毒擴散 | 火焰塔 + 毒塔相鄰 | 燃燒敵人死亡時擴散中毒 |
| 砲火陣地 | 3 座砲塔存在 | 所有砲塔爆炸範圍 +15% |
| 狙擊標記 | 狙擊塔 + 破甲塔相鄰 | 被破甲敵人受到狙擊傷害 +40% |
| 時空封鎖 | 時空塔 + 冰塔相鄰 | 緩速效果額外 +10% |
| 聖光祝福 | 聖光塔周圍 2 格內有普通塔 | 普通塔攻擊力 +20% |
| 元素三角 | 火焰塔 + 冰塔 + 雷塔同時存在 | 每 10 秒觸發一次元素爆發 |
| 經濟連線 | 2 座金幣塔相鄰 | 擊殺金錢 +8%，最多觸發一次 |
| 神話核心 | 神話塔周圍有 3 種不同稀有度塔 | 神話塔解鎖終極效果 |

### 合成塔範例

| 合成塔 | 需求 | 效果 |
|---|---|---|
| 暴風塔 | 冰塔 Lv.5 + 雷塔 Lv.5 | 連鎖雷擊並附加緩速 |
| 煉獄塔 | 火焰塔 Lv.7 + 毒塔 Lv.7 | 持續範圍傷害，敵人死亡爆炸 |
| 審判塔 | 聖光塔 Lv.10 + 狙擊塔 Lv.7 | 對 Boss 額外傷害，低血量處決 |
| 時裂塔 | 時空塔 Lv.10 + 魔法塔 Lv.9 | 有機率短暫停止敵人 |
| 王座塔 | 神話塔 Lv.12 + 3 種傳說塔 | 全場唯一終局塔 |

## 平衡限制

- 同一組合效果不可無限疊加
- 每座塔同時最多參與 1-2 個組合
- 強力組合需要等級門檻
- 合成塔需要消耗原本塔與金錢
- 神話與傳說組合要有數量限制
- Buff 型組合要有上限，例如最多 +30%
- 控場效果需要抗性遞減，避免敵人永久無法移動
