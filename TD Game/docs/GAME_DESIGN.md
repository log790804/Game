# 塔防遊戲設計規劃

## 核心概念

玩家在地圖上的可建造區域放置防禦塔，阻止敵人沿路徑抵達終點。每一波敵人會逐漸變強，玩家需要利用塔的升級、技能、科技樹、組合塔與難度策略完成關卡。

## 建議技術

- Frontend：Vue 3
- Build Tool：Vite
- Language：TypeScript
- Game Runtime：Phaser
- Save：localStorage，後續可擴充到 API 或雲端存檔

## 核心玩法

- 敵人從起點沿指定路徑移動到終點
- 敵人抵達終點會扣玩家生命
- 玩家消耗金錢建造防禦塔
- 防禦塔自動攻擊範圍內敵人
- 擊殺敵人獲得金錢與分數
- 每波敵人結束後可整備、升級、調整塔位
- 通關後依表現給予星數與科技點

## 關卡系統

- 多關卡地圖
- 每關不同路徑、可建造格、敵人組合與波次
- 關卡星數：1 星通關、2 星剩餘生命達標、3 星無損或高分
- 關卡解鎖：完成前一關後解鎖下一關
- 每關可指定推薦塔、特殊限制或環境效果

## 難度選擇

| 難度 | 敵人血量 | 敵人速度 | 金錢收益 | 適合玩家 |
|---|---:|---:|---:|---|
| 簡單 | 80% | 90% | 120% | 新手 |
| 普通 | 100% | 100% | 100% | 標準體驗 |
| 困難 | 130% | 110% | 90% | 熟悉系統 |
| 地獄 | 170% | 125% | 80% | 挑戰玩家 |

## 技能系統

技能作為玩家主動操作的戰術工具，不取代塔的核心價值。

| 技能 | 類型 | 說明 |
|---|---|---|
| 隕石轟炸 | 傷害 | 指定範圍造成大量傷害 |
| 冰霜領域 | 控場 | 指定範圍緩速敵人 |
| 金幣祝福 | 經濟 | 短時間擊殺收益增加 |
| 時間停止 | 控場 | 短時間停止部分敵人 |
| 緊急修復 | 防守 | 恢復少量基地生命 |

## 成就系統

- 首次通關
- 無損通關
- 擊殺指定數量敵人
- 建造指定數量塔
- 使用技能達成指定次數
- 完成每日挑戰
- 解鎖指定科技
- 完成特定組合塔

## 存檔系統

存檔以本機 localStorage 為第一版目標。

需要保存：

- 已通關關卡
- 每關最高星數
- 科技樹進度
- 成就進度
- 每日挑戰完成紀錄
- 玩家設定：音量、難度、觸控偏好

## 每日挑戰

- 依日期產生固定種子
- 每日指定地圖、難度與限制條件
- 可限制可用塔、技能冷卻、金錢收入或敵人種類
- 每日完成後提供科技點、徽章或成就進度

## 音效與背景音樂

- 主選單 BGM
- 戰鬥 BGM
- Boss BGM
- 建塔音效
- 升級音效
- 子彈命中音效
- 敵人死亡音效
- 技能音效
- 勝利與失敗音效

## 行動版觸控操作

- 點擊塔位建塔
- 點擊已建造塔顯示資訊
- 長按顯示攻擊範圍與詳細數值
- 觸控技能列施放技能
- 手機版 HUD 要避免遮住路徑與建造格
- 建議以橫向畫面為主要體驗
